# Tessera 更新日志

## 1.1.3 · 2026-10-18
- 冷启动后自动检查更新，发现新版本时弹窗展示更新内容，检查失败静默处理
- 关于页展示完整的历史更新日志，并标记当前版本
- 手动「检查更新」的弹窗同样包含本版本更新内容
- 修复首页顶部空白过多的问题
- 修复编辑页分类较多时排版错乱、留出大片空白的问题

## 1.1.2 · 2026-10-18
- 冷启动显著提速：验证码出现时间由约 2.8 秒缩短到约 1.2 秒
- 启动时并行预热加密数据库与账号密钥，并缓存解密结果
- 冷启动静默同步延后，避免与首屏加载争抢资源
- 排序页显示账号的原始图标
- 支持在分类内拖动调整验证码顺序
- 顶栏标题改为「凭牌」，点击标题或底部「验证码」可回到顶部
- 分类较多时改为横向滚动，不再换行

## 1.1.1 · 2026-10-17
- 新增排序页：拖动调整分类文件夹与验证码的显示顺序
- 首页分类文件夹支持长按拖动排序（含「未分类」）
- 关于页新增「检查更新」
- 修复顶栏切换分类时的卡顿

## 1.1.0 · 2026-10-15
- 新增 S3 对象存储同步后端，兼容 AWS S3 / R2 / B2 / MinIO / 阿里云 OSS / 腾讯云 COS
- WebDAV 支持配置多台服务器，每台可使用独立文件名
- Google Drive 与 OneDrive 支持绑定多个账号
- 每种同步后端都可设置备注名
- 新增分类（文件夹）管理，云同步会一并携带分类
- 新增 Tessera 专属导出/导入格式，可选密码加密
- 设置页新增图标，新增「关于」页，同步后端与云端数据独立成页
- 云同步支持删除指定后端上的云端备份

## 1.0.0 · 2026-10-13
- 首个正式版本
- 本地加密 TOTP：条目密钥由 Android Keystore 保护，数据库使用 SQLCipher 加密
- 支持扫码、相册识别与手动输入添加账号
- 支持 WebDAV、S3、GitHub、Gist、Gitee、Google Drive、OneDrive 七种同步后端
- 同步包使用独立同步口令端到端加密
- 提供回收站、应用锁与生物识别
- 内置图标库并自动匹配常见服务图标
